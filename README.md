## Hi there 👋

I'm Bedirhan — I build things for the web and I like knowing exactly how they work under the hood.

My path here wasn't a straight line: after my Abitur in 2019 I worked with kids, spent time in logistics, ran shifts in hospitality (my first taste of real responsibility and leading a team), and started a teaching degree before deciding it wasn't for me. Along the way one thing kept showing up: I'm the person who figures out the software, spots the detail everyone else missed, and can't stop asking *why does this work?*

In **October 2025** I started learning HTML, CSS and JavaScript alongside a full-time job. In **January 2026** I cut down to part-time so I could split my week 50/50 between work and learning — mostly through **freeCodeCamp**, plus building my own projects end to end. The moment it really clicked was seeing *my own* JavaScript actually do something.

From **October 2026** I'll be starting a part-time degree at **FernUniversität in Hagen** while I keep shipping.
